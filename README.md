# Titanic Survival Prediction – Final Data Science Project

## 1. Project Objective
To analyze Titanic passenger data and build a machine learning model to predict passenger survival.

## 2. Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 3. Data Analysis
The dataset was explored to understand passenger information, missing values, gender, age, passenger class, and survival.

## 4. Machine Learning
A Random Forest Classifier was trained using passenger details to predict survival. The dataset was divided into training and testing sets to evaluate the model.

## 5. Results
The model was evaluated using accuracy, precision, recall, and F1-score. The accuracy value is displayed in the model output above.

## 6. Conclusion
This project helped me understand data preprocessing, exploratory data analysis, machine learning model training, and model evaluation. It improved my practical knowledge of Python and Data Science.
